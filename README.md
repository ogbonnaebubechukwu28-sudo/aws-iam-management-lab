# AWS IAM Management Lab

## Objective
Practice identity and access management on AWS by creating IAM users, groups, and policies.

## Steps Performed
1. Created 2 IAM Users: Developer-User and Admin-User
2. Created 2 IAM Groups: Developers and Administrators
3. Attached ReadOnlyAccess policy to Developers group
4. Attached AdministratorAccess policy to Administrators group
5. Added Developer-User to Developers group
6. Added Admin-User to Administrators group
7. Enabled MFA for Admin-User
8. Tested permissions by signing in as each user
